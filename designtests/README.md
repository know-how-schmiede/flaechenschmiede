# Designtests

Dieses Verzeichnis enthält Design-Prototypen für die spätere Frontend-Umsetzung.

## Ziel

- Vergleichbare Referenz für Light- und Dark-Theme
- Sichtbare Sammlung späterer Standard-Elemente
- Grundlage für Design-Tokens, Klassenkonventionen und CSS-Regeln

## Enthaltene Elemente

- Sidebar, Topbar, Navigation, Tabs
- Buttons (Primary, Secondary, Ghost)
- Karten, Metriken, Badges
- Formulare (Input, Select, Checkbox, Textarea)
- Alerts, Progressbar, Tabelle
- Dialog und Toast
- Profileinstellung für Theme-Auswahl (Hell, Dunkel, System)

## Nutzung

Datei `index.html` direkt im Browser öffnen.

Hinweis: Das Prototyping ist absichtlich framework-neutral gehalten, damit die
Stilentscheidungen später in React/Material UI gezielt übernommen werden können.
