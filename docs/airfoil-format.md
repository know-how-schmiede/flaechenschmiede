# Profilformat

Die Profilbibliothek ist unabhängig von Geometrie-Plugins. Klassische Profile
werden als normierte Koordinaten samt stabiler ID, Name, Beschreibung,
Kategorie, Dicke, Wölbung, Anwendung, Quelle, Nutzungsstatus und Version
gespeichert.

Koordinaten dürfen erst aufgenommen werden, wenn Quelle und
Weiterverwendungsrecht dokumentiert sind.

KFm-Profile werden parametrisch aus Materialstärke, lokaler Flügeltiefe,
Stufenposition, Lagen, Stufenhöhe, Nasenausführung und Holmposition erzeugt.
Das konkrete maschinenlesbare Format wird in Phase 1 versioniert definiert.
